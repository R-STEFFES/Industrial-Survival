# Industrial Survive

This is a Minetest Based Game with focus on Realism, Automation and Exploring

it's work in Progress but there features to Explore! Fluidtanks, Carts with motor or Airplanes.

Minetest Game is the Base

## Installation

Download the Repo and move the folder in your Local luanti folder in the folder: games

### ContentDB

Currently not on ContentDB

### Manually

    - Unzip the archive, rename the folder to `Industrial Surival` and
place it in `.../games/`



The Luanti engine can be found at [GitHub](https://github.com/minetest/minetest).

For further information or help, see: [Installing Mods](https://wiki.luanti.org/Installing_Mods).
