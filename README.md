Industrial Survival

Industrial Survival is a standalone game for Luanti (formerly Minetest) with a strong focus on realism, automation, and exploration.

From humble beginnings to complex industrial manufacturing: set the foundation for your own industrial empire.
Features

While the game is currently in active development, it already offers extensive gameplay elements:

    Complex Industry: Utilize fluid tanks and intricate production chains.

    Mobility: Engineer motorized carts or take to the skies with custom airplanes.

    Expeditions: Venture into the wilderness to hunt for rare resources like uranium, specialized sands, and rare earth elements.

Note: Industrial Survival is built upon the Luanti engine.
Installation
Manual Installation

    Download the repository as a ZIP file.

    Extract the archive.

    Rename the folder to industrial_survival (using lowercase and underscores is the standard for Luanti/Minetest game identifiers).

    Move the folder into your local Luanti directory under games/.

        Path example: .../luanti/games/industrial_survival/
